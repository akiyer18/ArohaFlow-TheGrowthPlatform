# WIP limits and More Tools

Without caps, Goals sprawl and the Day Plan stops being realistic. Without a side door, useful but non-core surfaces (Journal, Knowledge) either clutter primary nav or disappear. **Decision:** max 3 Active Actions and max 5 Microactions on a Day Plan. Primary nav is Today, Calendar, Goals, Applications, Money, Food, Habits. **More Tools** holds Journal, Knowledge Expansion, and new experiments only. Task Manager and Flow Mode stay **legacy** (not listed in More Tools; not primary; not deleted from the repo on day one).
