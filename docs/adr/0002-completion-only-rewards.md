# Daily Points are awarded only on Completion

Time-tracking and "showed up" credits would make the Day Plan feel busy without proving progress. The user wants drive from finishing gym, Microactions, and Actions — not from sitting in a two-hour Block and leaving work unfinished. **Decision:** Daily Points (and any streak progress tied to scored work) are granted only on Completion events: Habit Check-in, Microaction marked done, or Action closed. Occupying a Block or exhausting its time window without Completion awards nothing.
