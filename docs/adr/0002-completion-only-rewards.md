# Daily Points are awarded only on Completion

Time-tracking and "showed up" credits would make the Day Plan feel busy without proving progress. The user wants drive from finishing gym, Microactions, and Actions — not from sitting in a two-hour Block and leaving work unfinished. **Decision:** Daily Points (and any streak progress tied to scored work) are granted only on Completion events: Habit Check-in, Microaction marked done, Action closed, or **Plan-ready Completion** (see amendment). Occupying a Block or exhausting its time window without Completion awards nothing.

## Amendment (Today execution board — #19)

**Plan-ready points are a Completion.** When the user locks tomorrow’s Day Plan the evening before (Intention + Blocks committed), the following calendar day starts with a **Plan-ready Completion** worth 10 Daily Points (weight in ADR-0003). If they did not lock tomorrow the evening before, there is no Plan-ready Completion and that grant is 0. This is not time-credit or “showed up”: it rewards the explicit lock ritual that makes Today executable. Further points that day still come only from other Completions.
